# V38–V40 Live CAS library implementation and runtime evidence

This candidate extends the prior verified V36 live-color/Alien → Vampire →
Alien leaf. V38's actual catalog-selection leaf now passes; V39 adds the
foreground-independent renderer and public CLI lifecycle integration.

## Implemented

- Bounded SQLite/FTS5 pages served at loopback port 8023, with no game commands.
- Windows read-only index lease; source bytes rehashed for selection.
- F11 search, all discovered categories including future numeric body types,
  EA/CC filters, friendly/package/code modes, two to eight virtualized columns,
  60-item pages, persistent favorites and recently inspected items.
- Selected-item assets use actual cached thumbnails where available and the
  verified independent package-copy Studio broker. Missing images stay explicit.
- `studio open-library` opens the correct native panel directly.
- `studio catalog-preview` checks exact form/save/appearance/outfit/row,
  loaded CASP TGI/hash/body type, and age/species before preparing a journaled
  replacement or empty-category insertion. Existing-item reselection retains
  exact color/layer state. Apply and Undo/Redo use the canonical history.
- First-click ownership uses the rendered F11 bounds, retaining release
  ownership outside the panel; the preceding frame's mouse-hover flag no
  longer determines whether a burst's initial click reaches the game.
