# Merged clothing mesh material split

Apply this research patch after the four-material diagnostic patch. It introduces an explicitly bounded per-triangle material split for one merged mesh, so a source-bound top/bottom pair can retain separate textures while preserving the existing four-mesh pose-cache layout. Invalid mesh index, material index and empty/out-of-range splits are refused. Existing calls without a split retain their prior material mapping. Diagnostic culling is refused with a split because the current face-pair detector does not account for material ownership.

A synthetic test compared a split merged mesh to two separate meshes at two yaw angles, including a per-material cutout mask, and confirmed pixel, coverage and triangle-count equality; invalid split values were rejected. One private source-bound rest-pose fixture also produced exactly matching outputs between the split and independent-mesh routes for real atlases and a synthetic overlapping bottom atlas. Across 23 cached poses at three yaw angles each, all 69 labeled-material frames matched pixel-for-pixel. These tests establish equivalence between two diagnostic render paths for those inputs, not native game rendering fidelity or arbitrary CC compatibility.

The candidate passed 117 core tests and 130 preview-server tests, with 10 server tests ignored. A clean patch application passed the focused split test and built both diagnostic examples. The split renderer is not connected to on-demand staging or the CAS room; real overlapping CC, shader correctness, full animation coverage, browser acceptance, game behavior and native fidelity remain unverified. No private source packages, pose files, configurations or frames are included.
