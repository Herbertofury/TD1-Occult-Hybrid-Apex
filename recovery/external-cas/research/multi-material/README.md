# Independent clothing material diagnostic

This isolated source patch extends the existing CPU preview renderer's material-input limit from three to four and adds a private rest-pose diagnostic. It assigns separate composed textures to the top and bottom meshes, a lower-stack texture to the head/shoes and a cutout texture to hair. Unlike the current pair builder, separate mesh materials can represent overlapping texture-atlas coordinates without merging the top and bottom textures into one atlas. This is a research renderer, not an integrated selector or a native game material implementation.

A synthetic unit fixture puts two triangles at different screen positions with the same UV coordinates and verifies that their separate red and blue material inputs remain distinct; a fifth material is rejected. In a separate private rest-pose experiment using one prepared source set, a synthetic fully opaque bottom atlas overlapped 656,772 nonzero-alpha top texels. Replacing only the bottom atlas changed all 16,105 blue-labeled bottom pixels and none of 10,271 red-labeled top pixels in that fixture. Labels come from an additional diagnostic render, not a native game mask. Source assets, derivatives and frames are not included.

The candidate passed 116 core tests and 130 preview-server tests; 10 server tests were ignored. A clean patch application passed the focused four-material test. The old three-material path was retained, but no general memory, performance or production stability claim is made.

The diagnostic is rest-pose only. Native material, blending, skin, layer ordering, clipping, pose, age/rig compatibility, real overlapping CC assets, browser acceptance and game parity remain unverified. The main source-bound pair preparation still refuses overlapping atlases and does not use this experimental path. The patch is relative to the retained post-v138 paired-face source including the optional solid-color diagnostic. Preserve creator assets privately.
