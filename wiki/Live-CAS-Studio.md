# Apex Live CAS Studio

**CAS Anywhere:** edit Sims from Live Mode/F11 with CAS-grade controls instead of opening Create-a-Sim for routine appearance work.

## Authorized MCCC baseline

The project owner has full permission from the MCCC author to use the relevant MC CAS, MC Dresser and shared CAS-related implementation material.

Current verified public baseline: **MCCC 2026.5.0** for Sims 4 PC 1.128.90.1030.

Apex starts from that real working behavior and improves it. MCCC is not required in the final install.

## What Apex should do outside CAS

- edit body/face modifier values;
- edit CAS parts by category;
- edit CAS-managed identity/preferences where runtime-safe;
- inspect every outfit category and slot;
- copy an outfit to another category;
- copy an outfit to another Sim;
- copy all outfits between Sims;
- copy Face / Body / full CAS appearance;
- copy only selected categories;
- paste from Saved Forms/history/presets/Tray Sims;
- save/load/tag/favorite appearance and outfit presets;
- randomize full outfit or selected body type;
- include/exclude/lock items visually;
- edit exact human/occult form lanes;
- perform bulk selected-Sim appearance operations;
- preview every change;
- Undo/Redo everything.

## Better than MCCC

Apex adds:

- one visual F11 workspace instead of scattered menu/console commands;
- Photoshop-style history and branching;
- semantic before/after diffs;
- exact hybrid form targeting;
- missing-CC/pack diagnostics;
- searchable Tray/Sim/preset sources;
- all-outfit and whole-appearance transaction previews;
- integrated CAS unlock catalog;
- integrated Saved Forms;
- patch-aware CAS metadata;
- explicit runtime verification;
- no MCCC dependency.
