## Definition of done
- [ ] Record game patch, packs, OS, mod profile and exact package/script/native artifact hashes.
- [ ] Exercise actual F11 and gameplay paths, not only helpers or mocked menus.
- [ ] Verify Sim/form/outfit ownership, exact colors and scoped edits through CAS, switching, travel, save/reload and Undo/Redo.
- [ ] Cover missing CC/packs, stale snapshots, unsupported special states, multiple Sims and representative hybrids.
- [ ] Confirm accurate catalog images, source resource identities and dependency mappings.
- [ ] Compare numeric slider values to authoritative data; distinguish possible collisions from confirmed conflicts.
- [ ] Measure startup, catalog/indexing latency, memory and gameplay frame-time tails on equivalent workloads. No arbitrary content caps or quality reduction.
- [ ] Verify hidden overlay performs no polling and expensive work is bounded by actual user/events.
- [ ] Include failures and unsupported cases in the report; do not mark a feature complete because its documentation exists.

## Useful bug report
Include the feature, expected result, actual result, exact reproduction steps, Sim/form/outfit context, patch/build identity, minimal implicated mod versions and sanitized logs/screenshots. Distinguish saved-data loss from a visual-only failure. Keep personal saves and credentials private.
